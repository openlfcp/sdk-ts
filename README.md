# openlfcp/sdk-ts

Reusable TypeScript implementation of LFCP.

This package must not depend on Obsidian or any other editor.

## Status

Repository scaffold only. The workspace and package layout
(core, wire, client, storage, profile) is set up in LFCP-011.

## Build from a clean checkout

```sh
pnpm install --frozen-lockfile
pnpm run build
pnpm test
```

Requires Node.js 24 or later and pnpm 10.
